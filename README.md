# EnjoyMyShow 🎬
A Java-based Spring Boot application for managing and discovering shows and Enjoy shows.

## 🚀 Features
----> User Authentication:Secure registration and login for users by using JWT.
----> Show Management: (CRUD operations for shows).
----> Data Transfer Objects (DTOs): Optimized data handling using custom Dto classes.

## 🛠️ Tech Stack
----> Language:** Java 17
----> Framework:** Spring Boot 3.x
----> Build Tool:** Maven
----> Database:** MySQL

## 🏗️ Project Structure
--> `controller/`: Handles HTTP requests (e.g., AuthController).
--> `dto/`: Data Transfer Objects for API requests and responses.
--> `entity/`: Database models.
--> `service/`: Contains the core business logic.
